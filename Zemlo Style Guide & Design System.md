# 🎨 Zemlo Style Guide & Design System

This document outlines the design system, typography, colors, and components used in the Zemlo project.

## 📦 Tech Stack & Libraries

### Core Framework

- **Next.js 15** - React framework with App Router
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS framework
- **pnpm** - Package manager

### UI & Styling

- **Custom Components** - Built in-house for full control
- **clsx** - Conditional className utility
- **tailwind-merge** - Merge Tailwind classes properly

### Icons

- **Lucide React** - Consistent icon library

## 🎯 Design Philosophy

- **Clean & Modern** - Minimalist design with ample white space
- **User-First** - Intuitive and accessible interfaces
- **Consistent** - Unified design language across all components
- **Performant** - Lightweight and fast-loading components
